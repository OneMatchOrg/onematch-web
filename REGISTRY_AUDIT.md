# OneMatch Registry Audit

Every registry published in OneMatch is manually verified before being added to the platform.

## L3 Verification Standard

A registry is marked as **Verified** only when:

- The website is official.
- The user lands on the shortest verified path to registration.
- No unnecessary intermediary pages exist.
- The registration flow has been manually reviewed.
