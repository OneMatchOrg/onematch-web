# Changelog

All notable changes to OneMatch will be documented in this file.

The format is inspired by Keep a Changelog and follows Semantic Versioning.

## [0.1.0] - 2026-09-08

### Added

* 25 verified L3 official donor registries.
* Direct registration-first navigation.
* Browser language prioritisation.
* Multilingual country search.
* Official registry transition before external navigation.
* Optional Portugal information page (ⓘ).
* Product Principle documented in the repository.

### Infrastructure

* Automatic `sitemap.xml`.
* Automatic `robots.txt`.
* First public GitHub Release (`v0.1.0`).
